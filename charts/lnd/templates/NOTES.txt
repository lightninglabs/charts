LND RPC can be accessed via port {{ .Values.lnd.service.rpcPort }} on the following DNS name from within your cluster:
{{ template "lnd.fullname" . }}-int.{{ .Release.Namespace }}.svc.cluster.local

To connect to lnd RPC:

1. Forward the RPC port:

  $ export LND_POD=$(kubectl get pods --namespace {{ .Release.Namespace }} \
    -l "app={{ template "lnd.name" . }},release={{ .Release.Name }}" \
    -o jsonpath="{ .items[0].metadata.name }")

  $ kubectl port-forward --namespace {{ .Release.Namespace }} $LND_POD {{ .Values.lnd.service.rpcPort }}

2. Copy the TLS cert and macaroon locally:

  $ kubectl cp --namespace {{ .Release.Namespace }} \
    $LND_POD:/data/tls.cert /tmp/lnd-tls.cert

  $ kubectl cp --namespace {{ .Release.Namespace }} \
    $LND_POD:/data/chain/bitcoin/{{ .Values.global.network }}/admin.macaroon /tmp/lnd-admin.macaroon

3. Query the node with your local lncli:

  $ lncli --network {{ .Values.global.network }} \
    --rpcserver localhost:{{ .Values.lnd.service.rpcPort }} \
    --tlscertpath /tmp/lnd-tls.cert \
    --macaroonpath /tmp/lnd-admin.macaroon \
    getinfo

Alternatively, query directly from within the pod:

  $ kubectl exec -it --namespace {{ .Release.Namespace }} $LND_POD -- \
    lncli --network {{ .Values.global.network }} \
    --tlscertpath /data/tls.cert \
    --macaroonpath /data/chain/bitcoin/{{ .Values.global.network }}/admin.macaroon \
    getinfo
